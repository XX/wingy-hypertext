Сейчас для большинства компонентов приходится писать бойлерплейт вида:
```rust
impl<R: Renderable> Renderable for Badge<R> {
    fn render_to(&self, buffer: &mut Buffer) {
        let children = renderable::as_dyn(&self.children);
        self.render_to(buffer, children)
    }
}
```
Лучше генерировать этот код с помощью derive-макроса в `wingy_hypertext_macros`. Нужно предусмотреть вариант для нескольких полей, не только `children` (у нас есть такие компоненты) и вариант простой делегации вызова при отсутствующих полей для конвертации в `dyn Renderale`. Метод, которому делегируется вызов - по умолчанию `render_to`, но может задаваться пользователем с помощью атрибута `#[render_to(...)]`. Вероятно функцию `renderable::as_dyn` лучше перенести, чтобы не требовался её явный импорт в пользовательском коде.
